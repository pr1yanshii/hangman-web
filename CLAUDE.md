# CSE 4095 Hangman Project

Build an original web-based Hangman application.

## Stack
- Python 3
- Flask
- HTML, CSS, vanilla JavaScript
- pytest
- Gunicorn
- Render

## Required
- Game engine independent of Flask
- Easy, Medium, Hard difficulty
- REST API: create, get state, guess
- Interactive browser interface
- Tests and deployment

## Out of scope
- Terminal clients
- Automated bots
- Evaluation systems
- Leaderboards
- Scoring systems

## Development rules
- Follow Specification.md and the revised TODO.md.
- Implement one phase at a time.
- Test before marking tasks complete.
- Never reveal hidden words during active games.
- Do not copy instructor source code.
- Do not commit secrets.

## Token efficiency
- Keep responses under 150 words when possible.
- Read only relevant files.
- Do not repeat file contents.
- Do not print entire source files.
- Avoid unnecessary tools or agents.
- Report files changed, test results, and blockers.
- Do not implement future phases.
- Do not skip necessary tests.
